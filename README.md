# 여행 일정 관리 프로그램 (Trip Schedule Project)

## 1. 프로젝트 소개

사용자의 여행 목적과 취향에 맞는 여행 일정을 생성하고 관리할 수 있는 프로그램입니다.
사용자가 여행 국가, 지역, 여행 기간, 인원 및 선호하는 여행 스타일을 입력하면 맞춤형 여행 일정을 제공하는 것을 목표로 합니다.
AI API를 활용한 여행 일정 생성 기능을 제공하며, 여행 일정의 추가·조회·수정·삭제 및 예상 비용 계산 기능도 구현합니다.

## 2. 프로젝트 목표

- 사용자 취향에 맞는 여행 일정 생성
- 여행 일정의 체계적인 관리
- 여행 예상 비용 계산
- AI를 활용한 개인 맞춤형 여행 추천
- C언어와 Python을 연동한 프로그램 구현

## 5. 프로그램 개발 구조

본 프로젝트는 C언어를 중심으로 개발하고, C언어로 구현하기 어려운 AI API 관련 기능은 Python을 활용하는 방식으로 구성합니다.

- C언어: GUI 구현, 여행 정보 관리, 일정 CRUD, 검색, 비용 계산, 파일 입출력
- Python: AI API 요청 및 응답 처리
- 데이터 연동: JSON 형식을 활용하여 C와 Python 간 데이터 전달

## 7. 데이터 구조

프로그램에서 공통으로 사용할 주요 구조체는 다음과 같습니다.

- TravelInfo: 여행 국가, 지역, 기간, 인원, 취향 및 예산
- Schedule: 일정 번호, 날짜, 시간, 장소, 활동 내용 및 예상 비용
- CostInfo: 항공권, 숙박비, 식비, 교통비, 기타 비용 및 총비용
- PlaceInfo: 장소명, 국가, 지역, 장소 유형 및 예상 비용
